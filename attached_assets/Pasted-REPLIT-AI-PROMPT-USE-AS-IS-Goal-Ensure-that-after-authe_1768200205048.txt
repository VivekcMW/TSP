Goal:
Ensure that after authentication (login / OAuth callback), the application always stays on the custom domain and never redirects to *.replit.app.
The current issue is that after sign-in, the app redirects to
page-logic--nmreplitproject.replit.app/dashboard instead of the custom domain.
 
Hard Requirements (Do Not Violate)
1.	Do NOT hard-code any domain
o	No replit.app
o	No page-logic--
o	No fixed base URLs like http://localhost, https://xyz.com
2.	Redirects must be derived dynamically from the incoming request:
o	Use req.headers.host
o	Use x-forwarded-proto when available
3.	OAuth must continue working
o	LinkedIn / Google / any OAuth must remain functional
o	Redirect URIs must use the custom domain automatically
 
Required Code Changes
1️.Canonical Domain Redirect (Global Middleware)
Add middleware before all routes to force the custom domain and block Replit URLs.
app.use((req, res, next) => {
  const CANONICAL_HOST = "app.yourdomain.com"; // replace with actual custom domain
  const host = req.headers.host;

  if (host.includes("replit.app") && host !== CANONICAL_HOST) {
    return res.redirect(
      301,
      `https://${CANONICAL_HOST}${req.originalUrl}`
    );
  }

  next();
});
This ensures:
•	Replit URLs never persist
•	SEO-safe canonical URLs
•	Users can’t land on Replit domain even after login
 
2️.Fix Auth Callback Redirect Logic (Critical)
Find the authentication callback handler and REMOVE any fixed redirect like:
res.redirect("https://page-logic--nmreplitproject.replit.app/dashboard");
Replace with dynamic redirect logic:
const protocol = req.headers["x-forwarded-proto"] || "https";
const host = req.headers.host;

res.redirect(`${protocol}://${host}/dashboard`);
This must be used for:
•	Login success
•	Signup success
•	OAuth callback success
•	Session restore flows
 
3️.Fix OAuth Redirect URI Construction
