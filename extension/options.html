Save to TheSocialPundit

Connect the extension to your account with a key. Create a key in TheSocialPundit: open More connectors, then Save from any page. The key is shown once.

Usually https://www.thesocialpundit.com. Chrome asks to allow access to this address only.

Starts with tsp_cap_. Anyone with this key can add pages to your Shortlist. Revoke it in TheSocialPundit if you lose this device.
